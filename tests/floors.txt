# The fewest assertions each suite must report as passing.
#
# A suite that skips everything still exits 0, so a runner without broadwayd or
# the GTK typelibs would report "0 passed, 12 skipped" and leave CI green with
# the tray suite gone. CI reads this file, runs each suite once, and fails when
# the passed count comes in under the floor.
#
# Raise a number when the suite gains cases. Lowering one is a decision that
# belongs in the commit message.
#
# install-flow's floor is one below what it reports on a machine with the
# NetworkManager hook installed, because its last case skips on a machine
# without one and a skip is not a pass. That one case is environmental by
# design; every other case must pass everywhere.
