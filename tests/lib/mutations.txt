# One row per deliberate change to a shipped script, tab separated:
#
#   id <TAB> file <TAB> sed-expression <TAB> suite
#
# The expression is applied to a private copy of the tree, the named suite runs
# against it, and a suite that still passes means the change went unnoticed. Each
# change is a behaviour a user would care about, so a survivor is a hole in the
# suite rather than a curiosity.
